# Render Deployment Guide for OTD (Outfit of the Day)

This repository includes a native [Render Blueprint](https://render.com/docs/blueprints) specification (`render.yaml`) that configures both the **Backend API Service** and **Frontend Web Application** on Render with zero manual infrastructure setup.

---

## Architecture Overview

```
                      +-----------------------------+
                      |       Render CDN Edge       |
                      +--------------+--------------+
                                     |
               +---------------------+---------------------+
               |                                           |
               v                                           v
     +-------------------+                       +-------------------+
     |      otd-web      |  API Calls (CORS)     |    otd-backend    |
     |   (Static Site)   +---------------------->+   (Node Service)  |
     |   React + Vite    |                       | Express+TypeScript|
     +-------------------+                       +---------+---------+
                                                           |
                                                           v
                                                 +-------------------+
                                                 |   MongoDB Atlas   |
                                                 | (Cloud Database)  |
                                                 +-------------------+
```

1. **`otd-backend`** (Web Service, Node.js)
   - Runtime: Node 20+
   - Root Directory: `backend`
   - Build Command: `npm install --include=dev && npm run build`
   - Start Command: `npm start`
   - Health Check: `/health`

2. **`otd-web`** (Static Site, Global CDN)
   - Runtime: Static
   - Root Directory: `web`
   - Build Command: `npm install --include=dev && npm run build`
   - Publish Path: `./dist`
   - SPA Rewrite: `/*` -> `/index.html`

## Step-by-Step Deployment Instructions

### Step 1: Push Repository to GitHub
Ensure all changes, including `render.yaml`, are pushed to your GitHub repository:
```bash
git push origin <your-branch>
```

### Step 2: Create a Blueprint on Render
1. Log in to your [Render Dashboard](https://dashboard.render.com/).
2. Click **New +** in the top navigation bar and select **Blueprint**.
3. Connect your GitHub account and select the **`RupajiBalaji/OTD`** repository.
4. Select your deployment branch (e.g. `Balaji` or `main`).
5. Render will automatically detect `render.yaml` and parse the two services (`otd-backend` and `otd-web`).

### Step 3: Configure Environment Variables
Render will prompt you for the variables marked `sync: false`:

#### 1. Backend (`otd-backend`)
| Variable | Description | Example / Recommendation |
|---|---|---|
| `MONGO_URI` | MongoDB Connection String | `mongodb+srv://<user>:<password>@cluster0.mongodb.net/ai_fashion_otd?retryWrites=true&w=majority` |
| `CORS_ORIGIN` | Allowed Frontend Origin(s) | `https://otd-web.onrender.com` (or `*` for initial test) |
| `GEMINI_API_KEYS` | Gemini API Key(s) (comma-separated for auto-failover) | `AIzaSy...` |
| `JWT_ACCESS_SECRET` | Auto-generated by Render | *(Automatically filled by Render)* |
| `JWT_REFRESH_SECRET` | Auto-generated by Render | *(Automatically filled by Render)* |

#### 2. Frontend (`otd-web`)
| Variable | Description | Example |
|---|---|---|
| `VITE_API_BASE_URL` | Public endpoint for backend API | `https://otd-backend.onrender.com/api/v1` |

> [!TIP]
> On the first deploy, Render assigns default hostnames like `https://otd-backend.onrender.com` and `https://otd-web.onrender.com`. Once the services are created, verify that `VITE_API_BASE_URL` on `otd-web` points to your backend's URL with `/api/v1` appended, and that `CORS_ORIGIN` on `otd-backend` includes your `otd-web` domain.

### Step 4: Seed Initial Wardrobe & Demo Personas (Optional)
Once the backend is deployed and connected to MongoDB Atlas, you can seed the adult demo wardrobes:
1. In the Render Dashboard, open the **`otd-backend`** service.
2. Navigate to the **Shell** tab.
3. Run:
   ```bash
   npm run seed
   ```

## Verifying the Deployment

1. **Backend Health Check**:
   Visit `https://otd-backend.onrender.com/health` in your browser. You should receive:
   ```json
   { "status": "ok", "uptime": 42.1, "timestamp": "2026-11-08T14:45:00.000Z" }
   ```
2. **Interactive API Documentation**:
   Visit `https://otd-backend.onrender.com/api-docs` to view Swagger UI.
3. **Frontend Application**:
   Visit `https://otd-web.onrender.com` to explore the live application and test the animated stylized character try-on.
